# e-sthetic® Privatklinik Essen

Responsiver neuer Webauftritt mit warmen Naturtönen, lokal gespeicherten Schriftarten, aufbereitetem Logo und einer hochwertigen Bildwelt. Statische Website ohne Laufzeit-Abhängigkeiten.

## Lokal starten

```sh
npm run dev
```

Die Website ist unter http://localhost:4173 erreichbar. `npm run check` prüft die JavaScript-Syntax. Der veröffentlichte Ordner ist `dist/`.

## Funktionen

- Responsives Desktop- und Mobil-Layout, mobile Navigation
- Tastaturbedienbare Behandlungsfilter und native Informationsdialoge
- Klinik-Bildergalerie und FAQ-Akkordeons
- Direkter Zugang zur bestehenden Online-Terminbuchung, Telefon, E-Mail und Routenplanung
- Lokal gehostete Schriften und Bilder; kein Tracking und keine eingebetteten Drittanbieter
- Impressum und Datenschutz sind mit den offiziellen Seiten des Unternehmens verknüpft

## Inhalte und Bilder

Unternehmensangaben wurden auf https://www.e-sthetic.de am 03.11.2026 geprüft. Originale Klinik- und Arztfotos stammen vom Unternehmen; genaue Quellen stehen in `dist/assets/source-attribution.json`.
